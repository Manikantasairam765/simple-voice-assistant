# Python Voice Assistant (GUI)


![Python](https://img.shields.io/badge/python-v3-blue)
![License](https://img.shields.io/badge/license-Apache%202.0-green)

## Description
A simple desktop-based voice assistant developed using Python and Tkinter.  
The application listens to voice commands and performs basic web-based actions such as YouTube playback, Google search, and time queries.

## Features
- Real-time voice command recognition  
- Text-to-speech responses  
- User-friendly Tkinter graphical interface  
- Play songs or videos on YouTube  
- Search queries on Google  
- Announce current system time  
- Start and stop assistant controls  

## Technologies Used
- Python  
- SpeechRecognition  
- pyttsx3  
- Tkinter  

## How It Works
The assistant continuously listens for voice input when started.  
Recognized speech is processed using keyword-based logic, and the corresponding action is executed with voice feedback.

## Installation
Install the required Python libraries:
pip install SpeechRecognition
pip install pyttsx3
pip install pyaudio



## How to Run
Run the application using:

Click **Start** and speak a valid command.

## Sample Voice Commands
- play despacito  
- search for machine learning  
- what is the time  
- open google  
- stop  

## Limitations
- Internet connection required  
- No advanced AI or natural language processing  
- Limited to predefined commands
